# Portfolio Tracker

A personal finance dashboard for Indian investors. It pulls your **equity
holdings** from Angel One, **mutual fund** NAVs from mfapi.in, and
**Sovereign Gold Bond (SGB)** prices from public sources — then plots
them side-by-side with 8 world stock-market indices so you can see, at
a glance, whether you beat the market today.

![Portfolio vs World Indices — example output](charts/portfolio_compare_20260624.png)

> *The chart above is auto-generated by running `python3 equity_compare.py`.*

## What it does

Every run does four things, in parallel:

| Source | What you get |
|---|---|
| **Angel One SmartAPI** | Live LTP and previous-day close for every equity in your demat account. |
| **mfapi.in** | Latest NAV for every mutual fund in your `mfs.json`. |
| **mintbyte + IBJA** | Market price per gram for every Sovereign Gold Bond in your `sgbs.json`. |
| **Yahoo Finance** | Closing prices for 8 world indices (Nifty, S&P 500, Nikkei, Hang Seng, FTSE, DAX, KOSPI, Shanghai). Nifty is patched with NSE's official EOD print for accuracy. |

Then it draws a horizontal bar chart (PNG) and an interactive line
chart (HTML) so you can see your portfolio's day-change next to the
markets. Every snapshot is saved to a local SQLite database, so the
HTML chart grows over time and lets you answer questions like
*"am I beating Nifty over the last 6 months?"*

## Who this is for

You should be comfortable with:

- Running Python scripts from a terminal.
- Editing a `.env` file with your broker credentials.
- Optionally scheduling a daily cron job.

You do **not** need to be a programmer to use it. Once it's set up, the
only command you need each day is:

```bash
python3 equity_compare.py
```

## Quick start

> Assumes macOS or Linux with Python 3.10 or newer. On Windows, the
> commands are the same but use `py` instead of `python3`.

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/portfolio-tracker.git
cd portfolio-tracker
```

### 2. Create a virtual environment

This keeps the project's Python packages isolated from the rest of
your system.

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up your Angel One credentials

Sign in to the Angel One app, go to **My Profile → Developer Console**
(or visit https://smartapi.angelbroking.com/), and create an API key.
You'll get four values:

| Variable | What it is |
|---|---|
| `ANGEL_API_KEY` | The API key from SmartAPI dashboard. |
| `ANGEL_CLIENT_CODE` | Your Angel One client ID (e.g. `A12345678`). |
| `ANGEL_MPIN` | The 4–6 digit PIN you use to log in to Angel One. |
| `ANGEL_TOTP_SECRET` | The base32 string from the QR code in the SmartAPI dashboard (used to auto-generate TOTP). |

Copy the example file and fill in your values:

```bash
cp .env.example .env
nano .env        # or open in any editor
```

Your `.env` will look like:

```
ANGEL_API_KEY=AbCdEf12345
ANGEL_CLIENT_CODE=A12345678
ANGEL_MPIN=123456
ANGEL_TOTP_SECRET=JBSWY3DPEHPK3PXP
```

> **The `.env` file is in `.gitignore`.** It will never be committed or
> pushed to GitHub.

### 5. List your mutual funds

Edit `mfs.json` with the mutual funds you hold. The `name` is the
**exact** scheme name as it appears on the CAS statement or the AMC
website. `units` is how many units you hold:

```json
[
  {"name": "HDFC Mid Cap Fund - Growth Option - Direct Plan", "units": 500.58},
  {"name": "Parag Parikh Flexi Cap Fund - Direct Growth",    "units": 1234.5}
]
```

> Don't have a CAS handy? Just use [Kuvera](https://kuvera.in) or
> [MFCentral](https://www.mfcentral.com/) to download one, then run
> `python3 cas_parser.py path/to/cas.pdf` to auto-generate this file.
> The CAS PDF password goes in `secrets.local.json` (see step 6).

### 6. (Optional) Set your CAS PDF password

If you'll be parsing CAS PDFs, copy the secrets file:

```bash
cp secrets.local.json.example secrets.local.json
nano secrets.local.json
```

It will look like:

```json
{
  "cas_pdf_password": "the-PIN-you-set-on-CAMS"
}
```

### 7. List your SGBs

Edit `sgbs.json` with your Sovereign Gold Bond holdings. The `isin` is
on every certificate and on your demat statement:

```json
[
  {
    "isin": "IN0020230184",
    "units": 1,
    "name": "SGB 2022-23 Series IV (Feb 2032)",
    "buy_date": "2023-02-15",
    "invested_per_g": 7920
  }
]
```

### 8. Run it

```bash
python3 equity_compare.py
```

You should see something like:

```
2026-06-24 10:30 INFO | equity using SmartAPI prev_close  matched=11/11  pct=-0.26%  value=₹495,969
2026-06-24 10:30 INFO | chart saved: charts/portfolio_compare_20260624.png

  My Equity                      -0.26%   ₹       495,969
  My Mutual Funds (5)            -0.83%   ₹       350,273
  My SGBs (2)                    -1.29%   ₹        30,313
  My Total Portfolio             -0.52%   ₹       876,555
  -----------------------------------------------------
  Indices:
    Nifty 50 (IN)                +0.50%
    ...
```

A PNG chart appears at `charts/portfolio_compare_YYYYMMDD.png`. To
generate the interactive HTML chart (portfolio vs indices over time):

```bash
python3 portfolio_html.py --period 3mo
```

Open `charts/portfolio_compare_3mo.html` in any browser.

## Daily usage

Once set up, daily life is:

```bash
source .venv/bin/activate          # if not already in the venv
python3 equity_compare.py          # ~10 seconds, makes today's PNG
python3 portfolio_html.py --period 3mo   # ~5 seconds, refreshes the HTML
```

That's it. The HTML chart grows by one data point every day.

### Optional: also export just the indices

```bash
python3 indices_chart.py           # today's indices as a PNG
python3 indices_html.py --period 6mo   # interactive indices only
```

## What the charts show

### Bar chart (`equity_compare.py`)

A snapshot of today's % change for each index, plus your equity
portfolio. Mutual funds and SGBs are summarised in the box at the top
(they're typically reported a day later, so a side-by-side bar would
mix dates).

### HTML chart (`portfolio_html.py`)

Your **portfolio value** rebased to 100 on the chart's first day,
plotted alongside the same for each index. Hover to see exact values.
Use the range slider at the bottom to zoom into a specific window.

After a few days of running `equity_compare.py`, you'll see a black
line for "My Portfolio" that lets you compare your returns against
the indices over weeks and months.

## Configuration

There are three configuration files you may edit:

### `.env` — Angel One credentials (required)

| Key | Where to get it |
|---|---|
| `ANGEL_API_KEY` | SmartAPI dashboard after creating an app |
| `ANGEL_CLIENT_CODE` | Your Angel One client ID |
| `ANGEL_MPIN` | Your Angel One PIN |
| `ANGEL_TOTP_SECRET` | Base32 string from the TOTP QR code |

### `secrets.local.json` — CAS PDF password (optional)

Only needed if you parse CAS PDFs. Set `cas_pdf_password` to the PIN
you configured on CAMS / Kuvera / MFCentral.

### `mfs.json` and `sgbs.json` — your holdings

See the `.example` files for format. The `name` field for mutual funds
should be the exact scheme name; a fuzzy match is attempted if it's
slightly off.

### Environment variables (advanced)

| Variable | Default | What it does |
|---|---|---|
| `PT_LOG_LEVEL` | `INFO` | Set to `DEBUG` for verbose logs. |
| `PT_PARALLEL_WORKERS` | `8` | Number of threads for parallel fetches. Lower this if you get rate-limited. |

## Running automatically every day

To get a chart waiting in your inbox every morning, schedule it.

### macOS — launchd (recommended)

Create `~/Library/LaunchAgents/com.portfolio-tracker.daily.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.portfolio-tracker.daily</string>
  <key>ProgramArguments</key>
  <array>
    <string>/Users/YOU/portfolio-tracker/.venv/bin/python</string>
    <string>/Users/YOU/portfolio-tracker/equity_compare.py</string>
  </array>
  <key>WorkingDirectory</key>
  <string>/Users/YOU/portfolio-tracker</string>
  <key>StartCalendarInterval</key>
  <dict>
    <key>Hour</key><integer>16</integer>   <!-- 4 PM, after market close -->
    <key>Minute</key><integer>15</integer>
  </dict>
  <key>StandardOutPath</key>
  <string>/Users/YOU/portfolio-tracker/logs/launchd.out.log</string>
  <key>StandardErrorPath</key>
  <string>/Users/YOU/portfolio-tracker/logs/launchd.err.log</string>
</dict>
</plist>
```

Then:

```bash
launchctl load ~/Library/LaunchAgents/com.portfolio-tracker.daily.plist
launchctl start com.portfolio-tracker.daily    # run once now to test
```

### Linux — cron

```bash
crontab -e
```

Add:

```
15 16 * * 1-5 cd /home/YOU/portfolio-tracker && .venv/bin/python equity_compare.py >> logs/cron.log 2>&1
```

(Runs at 4:15 PM every weekday, just after NSE close.)

## Limitations & known issues

These are honest limitations, not bugs:

- **Angel One token cache is best-effort.** Angel One's API actively
  rejects token refreshes within minutes of fresh login as anti-abuse.
  Most runs will still hit the broker with a fresh TOTP + MPIN login.
  The cache occasionally short-circuits the login; when it doesn't,
  it falls back cleanly. Run time is unaffected.

- **IBJA gold prices are scraped**, not from an API. If ibjarates.com
  changes their HTML, SGB prices will silently fall back to the IBJA
  gold-spot proxy (which is the RBI benchmark anyway). Watch the logs
  for `[sgb] mintbyte: fetch failed` warnings.

- **mfapi.in is a free service** with no SLA. If they're down, MF
  rows in the chart will show stale prices. The chart still renders —
  it just doesn't refresh until they're back up.

- **The "My Portfolio" line in the HTML chart only appears after you
  have ≥ 2 daily snapshots in the database.** Run `equity_compare.py`
  for a few days and it'll show up.

- **CAS PDF parsing is heuristic.** It works for CAMS, Kuvera, and
  most MFCentral layouts. If your statement looks weird, run
  `python3 cas_dump.py your-cas.pdf` to see the raw text and open an
  issue with the first 30 lines pasted in.

- **No currency normalisation.** Indices are in their local currencies
  (S&P in USD, Nikkei in JPY, Nifty in INR). Your portfolio is in INR.
  On a day when the rupee moves a lot, the comparison is apples-to-
  oranges. A future version will rebase indices to INR.

## Security — what's safe to publish

This repo is **safe to push to a public GitHub repository**. Every
sensitive file is in `.gitignore`:

| File | What it contains | In `.gitignore`? |
|---|---|---|
| `.env` | Angel One API key, MPIN, TOTP secret | ✅ Yes |
| `secrets.local.json` | CAS PDF password | ✅ Yes |
| `mfs.json` | Your actual MF holdings | ✅ Yes |
| `sgbs.json` | Your actual SGB holdings | ✅ Yes |
| `data/history.db` | Daily portfolio snapshots (₹ values) | ✅ Yes |
| `logs/` | App logs (could contain debug info) | ✅ Yes |
| `charts/` | Generated PNG / HTML charts | ✅ Yes |

The shipped example files contain only placeholders:

- `.env.example` → `ANGEL_API_KEY=replace_me` etc.
- `secrets.local.json.example` → `"cas_pdf_password": "your_cas_password_here"`
- `mfs.json.example` → sample fund names, not your real ones
- `sgbs.json.example` → sample ISINs, not your real ones

### Before you push for the first time

Run the pre-publish check:

```bash
bash scripts/pre-publish-check.sh
```

It verifies nothing sensitive has slipped into the tracked files.

### Optional but recommended

On GitHub, go to your repo → **Settings → Code security and analysis**
and enable **Secret scanning** + **Push protection**. Free for public
repos. GitHub will then refuse any push that contains patterns
matching known API keys, broker credentials, or private keys.

## Troubleshooting

### "Angel One login failed: Invalid Token"

This is almost always one of:

1. **Wrong API key.** Re-copy from the SmartAPI dashboard.
2. **Wrong TOTP secret.** The QR code you scanned is base32 — make
   sure you copy the *string* shown below the QR, not the URL.
3. **System clock is off.** TOTP is time-based and drifts by ±30s.
   Run `sntp -sS time.apple.com` (macOS) or `sudo ntpdate pool.ntp.org`
   (Linux).
4. **IP whitelist mismatch.** Angel One's API requires you to
   pre-register your public IP. If you're on a VPN or your ISP
   rotates IPs, you'll see this.

### "ModuleNotFoundError: No module named 'SmartApi'"

You didn't install requirements. Run:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### "no holdings found" but I have stocks

Either:

- Your holdings are in a different broker (this only reads Angel One).
- Your Angel One session token is rejected (see above). Run
  `python3 test_connection.py` to diagnose.

### "mfapi.in failed for code X after 3 attempts"

Their service is flaky or rate-limiting you. Try again in a few
minutes. If it persists, lower `PT_PARALLEL_WORKERS=2` in your
environment.

### The HTML chart shows just the indices, no portfolio line

You don't have ≥ 2 daily snapshots yet. Run `equity_compare.py`
today and tomorrow; the line will appear on the third run.
